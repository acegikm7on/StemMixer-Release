StemMixer is a Windows AI stem separation app that separates a song into vocals, drums, bass, and instruments. HQ Vocal, pitch shift, per-stem mixing, YouTube playlist import, and WAV/MP3 export.

Features (StemMixer)

  • AI stem separation — vocals, drums, bass, other
  • HQ Vocal hybrid cloud separation
  • Pitch shift within ±2 semitones
  • Playback speed control
  • Per-stem volume mixer with presets
  • Local folders and YouTube URL / playlist import
  • Export mixed results as WAV or MP3

Workflow

OPEN → SPLIT → MIX → SAVE

  1. Open a song file or paste a YouTube URL.
  2. Run AI stem separation.
  3. Adjust pitch and per-stem levels.
  4. Export to WAV or MP3.
